## Mission

Write the first public-facing copy wave for the House Pendale site using the seeded page contracts and creative briefs already established in this repository.

This is not a freeform brand exercise.

The architecture is already decided. Your job is to fill the rooms without knocking down load-bearing walls like a drunk Victorian ghost.

## What success looks like

By the end of this wave, Lead Elly should have enough polished draft copy to:

- review the voice and public boundaries
- compare page tones against one another
- hand stable content requirements to Tech Elly
- identify where Substack should carry the deeper or more explicit burden

## Non-negotiable rules

1. Public site copy must stay suggestive, not explicit.
2. `Star in Harlem` does not belong on the public site.
3. Deep dives, intimate expansions, and anything explicit should route toward Substack rather than bleeding onto the main site.
4. The top-level magical systems are only:
   - `Pulse Resonance`
   - `Wordframe`
   - `Covenant`
5. Do not reintroduce `Mirror` as a live top-level system.
6. Do not use `Constellation Bonding` as a named architecture block.
7. The public character surface must center:
   - Elysia
   - Coren
   - Hannah
   - Rachel
   - Ezra
8. Socials are part of the brand surface, not an afterthought dumped into `Contact`.

## Deliverables

Produce working copy drafts for the following pages:

1. `Home`
2. `Books`
3. `When Stars Align`
4. `Characters`
5. `Magic Systems`

For each page, provide:

- hero headline
- hero support copy
- section headlines
- section body copy
- CTA labels
- optional microcopy where relevant
- one short note identifying anything that should be pushed to Substack instead of expanded on-page

## Page-by-page job

### 1. Home

This is the threshold page.

It must:

- make the House feel awake
- offer two clean reader paths:
  - `Read When Stars Align`
  - `Enter the House`
- establish mood without becoming a lore lecture
- include an elegant bridge to socials and Substack

It must not:

- become a generic author homepage
- over-explain the world
- perform explicit heat on the page

### 2. Books

This is the collection page for the reading path.

It must:

- reassure readers there is a clear place to start
- make `When Stars Align` feel like the right first door
- leave elegant room for future books

It must not:

- read like a product grid
- pretend the shelf is larger than it is
- drown the reader in series bureaucracy

### 3. When Stars Align

This is the chamber page for the current lead book.

It must:

- sell the book honestly
- communicate premise, emotional arc, and heat profile
- make the reader trust that the book has rules, stakes, and a payoff
- keep retailer actions direct and clear

It must not:

- spoil the whole book
- paste explicit material onto the public site
- sound like blurbs written by committee after three glasses of chardonnay

### 4. Characters

This is a real cast page, not a mood collage.

It must:

- introduce Elysia, Coren, Hannah, Rachel, and Ezra as actual entry points
- make each feel distinct
- create attachment and curiosity
- route the reader toward individual character interest or back to the book

It must not:

- treat the House or Liora as interchangeable with cast entries
- dump relationship algebra on the page
- flatten everyone into identical mysterious seduction mannequins

### 5. Magic Systems

This is the public orientation page for the world’s foundational systems.

It must:

- define `Pulse Resonance`, `Wordframe`, and `Covenant`
- make the systems feel coherent and alive
- give enough clarity that readers trust the world’s logic
- leave deeper or more unstable implications for Substack

It must not:

- turn into a metaphysics dissertation
- reintroduce deprecated system language
- over-pin fluid canon

## Tone calibration

Aim for:

- intelligent
- intimate
- dangerous
- restrained
- ritualized
- emotionally precise

Avoid:

- generic dark-romance boilerplate
- overwritten faux-poetic sludge
- fantasy textbook jargon
- empty mystery language that withholds so hard it says nothing
- author-brand puffery where the House should be leading

## Output format

Return the work page by page.

For each page use this structure:

1. Page name
2. Hero
3. Section blocks
4. CTAs
5. Substack deferral note

If there are alternate hero options worth considering, keep them brief and label them clearly.

## Review lens

Before handing anything back, self-check:

1. Does this sound like House Pendale rather than a generic genre site?
2. Does this keep the public site on the correct side of the explicitness line?
3. Does each page know what job it is doing?
4. Is anything trying to solve a Substack problem on the website?
5. Are there any canon locks here that we may regret in six months?

## Final instruction

Do not design the site.
Do not solve implementation.
Do not invent new architecture.

Write the copy the current architecture is asking for, and flag only the places where the architecture and the writing genuinely collide.
