# Pendaleverse Brief System

This folder is the design-side control room for the House Pendale site.

The point is simple:

- Lead Elly defines what each page is for.
- Creative Elly writes what the page says and implies.
- Tech Elly builds what the page does and supports.

Do not let those three realities drift apart.

## Working rule

Every important page starts with a page contract.

The page contract is the source of truth. Creative and tech briefs are derived from it. If a creative or technical decision conflicts with the contract, the contract wins until Lead Elly updates it.

## Folder structure

- `templates/` holds the reusable templates.
- `dispatches/` holds packaged handoff packets for Creative or Tech work waves.
- `pages/<page-slug>/page-contract.md` defines the page.
- `pages/<page-slug>/creative-brief.md` hands the page to Creative Elly.
- `pages/<page-slug>/tech-brief.md` hands the page to Tech Elly.

## Scope boundaries

Public site:

- books and reading entry points
- character introductions
- the House as a world threshold
- basic magic-system explanation
- brand mood, invitation, and orientation
- clear routing to Amazon, Substack, and social surfaces

Offsite / Substack:

- deeper essays
- intimate and explicit expansions
- fuller ritual and world deep dives
- material that should stay flexible while canon is still evolving

## Socials policy

Do not hide socials only on `Contact`.

The active social set should be treated as part of the brand surface:

- Threads
- Instagram
- TikTok
- X
- Bluesky
- Substack

Default placement logic:

- global footer: full set
- header drawer: selected `Follow the House` cluster
- `Join`: strongest social and Substack bridge
- `Contact`: business-first, socials secondary
